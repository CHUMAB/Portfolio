This is the README file for my portfolio website, but by no means do you have to READ IT. Please exercise your free will when on my github page.

This has been a painstaking project as I wanted to build my entire website from scratch and display all my work in my own way. The project is built with React and Next.js with Javascript, utilizing JSX components.

It is a work in progress asways, and will be updated with major developments in my work, particularly in the "current work" section.

This portfolio is designed specifically for desktop viewing, as the phone display screen is not sufficient for large landscape images, videos, or external links (ie. Figma). Mobile development is not something I am interested in persuing at this time.
