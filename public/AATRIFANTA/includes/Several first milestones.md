Several first milestones
First upload includes a couple weeks worth of progress, my major milestones roughly in order up until now are:
- Main menu with start settings and info pages
- Start sends to landing page with starting dialogue, options, and a character card
- Used the starting out card to creat all following info/dialogue cards
- Character card includes health bar, progress bar, a map section (possible feature later), gold, and an inventory
- Formatted the page to be easy to look at and work with
- Added a few intro choices to get used to the process of moving between info cards (areas)
- Added functionality to add and subtract health from the health bar
- Added a store that checks your gold and allows you to add items to your inventory - SWORD, ARMOR, and POTION
- Prevented purchase of multiples of a single item
- Created custom JSON data for the intro sequence including multiple paths to the 'HUB' area
- Created 3 directional choices for player to choose from
- Added a simple JSON-based scenario to set up combat encounter in the WEST tree
- Added an enemy with same health bar functionality, formatted to the right side of the screen - OGRE
- Added 2 combat options of ATTACK and USE POTION - may chance this functionality in the future
- ATTACK option deals variable damage with a chance to deal critical damage, variable damage is returned at the same time
- ATTACK option deals flat higher damage if a SWORDis equipped
- OGRE deals less damage if you are wearing ARMOR
- USE POTION checks for a potion in inventory and heals the user for a flat amount if they have one
- Added a random loot table to the OGRE upon death, user can receive one of 3 items based on chance
- Added selling functionality to the shop
- Blocked the user form re-entering an area they have already cleared
- Added death
- Added ability to use a potion anywhere straight from inventory, opening up the possibility for a change in the combat system



An adventure to remember if you are new to adventures

I am encouraged to make a README file but by no means do I require you to READIT. Please exercise your free will when on my GITHUB page there is nothing bad that can happen here.

I will be using this space for rambling and musing about the project, and it's eventual predessesor(s). This project is my final project for my ICS-128 course at Camosun College. It is a big idea I have worked hard to contain within what can be reasonably expected of me in the timeframe I was given. This project will be for my class, but the ideas, framework, and functionality can and may well be adapted in to a bigger project with more going on that would be beyond the scope of my project expectiations. This project will be rough around the edges and experimental, and is inteded to be fun.
